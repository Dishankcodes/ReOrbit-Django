# ReOrbit — User UI Rebuild

This version focuses on the logged-in **User side UI only**.

## Included
- Rebuilt responsive User sidebar + header
- Dashboard
- Marketplace with search, category filters, sorting and grid/list UI
- Product details
- Community seller profile
- ReMaker profile
- Orders
- Wishlist
- Donations
- Following
- Orbit Points
- Badges
- Settings
- Help & FAQ
- Shared mock data and reusable UI styling

## UI-only scope
No new backend/API logic was added. Pages use local mock data so the UI can be reviewed independently. Existing backend/API files remain in the project but are not required by the rebuilt logged-in User pages.

## Run
```bash
npm install
npm run dev
```

Open `/user-dashboard` to review the logged-in User experience.
